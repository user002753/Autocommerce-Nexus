USER MANUAL / TASK WALKTHROUGHS

How-To Guide — Complete Any Task in Seconds

Step-by-step instructions for every interactive demo on this site. Each card maps to a section of the page.

TASK 1

Run the 1-Click Guided Demo

  1. Click “🚀 Run 1-Click Guided Demo” at the top-right of the header (or the banner button under it).
  2. Watch the Agent Thought Stream — the agent negotiates, escalates, and defends against a prompt attack automatically.
  3. The floating phone on the right mirrors the buyer experience: WhatsApp chat → UPI QR → DAT mandate.
  4. Any step can be run individually using the four scenario buttons above the terminal.
TASK 2

Negotiate a Price & Check Out

  1. Scroll to the Marketplace catalogue (or use the search / category filters to find an item).
  2. Click the “+” button on any product card to open the negotiation modal.
  3. Drag the discount slider — the price floor is enforced automatically (margin never drops below 15%).
  4. Click Accept Protected Offer → the item lands in your Bag.
  5. Open the Bag (top-right), review the subtotal, then click Create Secure Payment and simulate the UPI payment.
TASK 3

Issue a Spending Policy (DAT Token)

  1. Go to the Buyer Cockpit section.
  2. Set the Daily and Per-Order spending ceilings with the sliders.
  3. Toggle which categories the agent may auto-purchase (Apparel requires human approval).
  4. Click Issue UPI Reserve Mandate (DAT Token) — you’ll receive a signed mandate code.
  5. Now agent prompts (Concept 1) and voice checkout can settle automatically within your limits.
TASK 4

Buy with a Natural-Language or Voice Prompt

  1. Text: In Concept Sandbox → AgentPay Protocol, type e.g. “Buy me 2 packs of blue running socks under ₹600” and click Execute AgentPay ⚡.
  2. Voice: Click the 🎙️ microphone in VoiceCommerce Mesh and speak in English or Hinglish — or use the preset Hinglish button.
  3. Danger test: Try the “Test Prompt Injection” chip — the margin sentinel will reject it and explain why.
TASK 5

Simulate Edge Cases & Recovery

  1. Open the Agent Flight Recorder → Failure Injection Sandbox.
  2. Arm one or more faults: bank 500 error, stock race, high-RTO pincode, or prompt injection.
  3. Click Arm Recovery Matrix, then repeat any purchase task.
  4. Watch the Live Reasoning Feed show the fault being trapped and auto-recovered (fallback link, alternative item, ₹100 waiver…).
TASK 6

Post-Purchase: SLA Tracking & Instant Refund

  1. After any successful checkout, scroll to the Concierge section — your order appears with a dispatch tracker.
  2. Click Simulate >48h Merchant SLA Breach to see the agent open an inquiry automatically.
  3. Trigger the 1-Click Razorpay Instant Refund and confirm the event lands in the Audit Ledger below.
